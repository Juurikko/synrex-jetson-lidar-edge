# RC1 → RC2 media changes

Copyright 2026 Tuomas Pietilä. CC BY 4.0 original presentation.

| RC1 | RC2 |
|---|---|
| 54 seconds, 24 fps | 49 seconds, 30 fps, 1080 × 1350 H.264 |
| Static geometry title opening | Immediate moving, close classified geometry with mobile-sized 2M headline and RTX 4090 replay disclosure |
| Cloud views in a small page panel, distant elevated viewpoint | Full-frame perspective stage; low forward/lateral tracks, close roof and vegetation passes, short controlled orbit |
| Multiple static holds | Continuously moving geometry throughout; measured frame differences and full decoded-frame count |
| Static input and prediction sections | Spatially aligned moving reveal and reverse reveal, using identical real source points and shared camera |
| 25 map snapshots held in an elevated view | 400,654 genuine native events replayed continuously; accelerated overview plus two active-crop detail replays, explicit retiming and repeat disclosure |
| Difficult to see map activity | Literal occupied voxel glyphs, white new-cell and cyan reobservation outlines; moving low cameras and activity-based crops |
| Dense static metric page | Two sequential cards over moving geometry, separated rate and ten-minute scopes |
| R4/streaming status less prominent | Native stack and scoped MIT BYOM end card, public R4 / unpublished streaming R2 status and repository URL |

No accepted runtime, model weight, trained output, benchmark receipt, historical failure or original RC1 asset is edited. RC2 adds offline rendering, QA, packaging, documentation and evidence only. It does not rerun or optimize native inference. The 48.756% held-out mIoU and visible prediction mistakes remain. The 274.478 ms diagnostic JSON p99 FAIL is retained and excluded from accepted performance claims.

RC2 expands the urban visual selection to one additional already-published, source-bound R4 output in the accepted RC1 archive; the original second urban scene and scene-C recording remain in use. Model/data rights are separately scoped. No public push, release, LinkedIn action or target-device access is performed.

Opening proof review corrected an aliased cell-centre point display to explicit voxel glyphs. A camera experiment that followed rapid record-order spatial sweeps was rejected for excessive motion; final detail cameras are controlled short orbits around actual activity-density peaks, with inactive outside-crop intervals skipped in event order. These are media choices only. The final camera and exact map-event stop for every frame are in the review package.

Owner publication approval is a future boundary; `RC2_OWNER_REVIEW=PASS` means the local review package is complete, not that the owner has approved publication.
